# Graph Auto Reader 1.0 readiness

## Decision

**FAIL.** Version `0.0.21` is an internal development checkpoint. Its build
number is on a public-release cadence, but the release is not ready and must
not be tagged or published. Required production models, clean-machine loading
for the reviewed native components, final PDFium and NCNN production approval,
private automatic supplied-example evidence, release artifacts, and
clean-Windows runtime evidence are absent.

`PASS` below means direct repository, command, or runtime evidence satisfies the
named gate. Component-level tests do not satisfy an end-to-end or clean-machine
gate. `FAIL` means the gate failed, is blocked, or has not been directly proven.

## Release decision and unblock conditions

Do not create a tag, GitHub release, installer, or portable release claim for
`0.0.21`. The next public version may be `1.0.1` only after all `FAIL` rows are
replaced with direct evidence. At minimum this requires:

1. A complete checksum-approved, redistributable production model set with
   release-eligible benchmarks and offline CPU execution.
2. Clean-machine loading and workflow evidence that permits the implemented
   common-publish promotion path to approve the exact reviewed OpenCV runtime.
3. Independent PDFium approval, a reviewed exact-binary public-audit component,
   and checksum-bound clean-machine render evidence that permits the implemented
   release-staging path to populate the common publish.
4. A production end-to-end run covering every Session 18 scenario.
5. An authorized private supplied-example run with the false-marker criteria.
6. Installer and portable artifacts built from one clean commit and verified
   for identical binaries, contracts, manifests, checksums, and notices.
7. Clean Windows VM install, portable, offline, path-isolation, repair,
   upgrade, uninstall, spaces, Unicode, and read-only-folder evidence.
