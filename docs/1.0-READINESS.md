# Graph Auto Reader 1.0 readiness

## Decision

**FAIL.** Version `0.0.20` is an internal build. It is not `1.0.1`, is not
eligible for a public release, and must not be tagged or published. Required
production models, complete OpenCvSharp native redistribution provenance,
private automatic supplied-example evidence, release artifacts, and clean-Windows runtime
evidence are absent.

`PASS` below means direct repository, command, or runtime evidence satisfies the
named gate. Component-level tests do not satisfy an end-to-end or clean-machine
gate. `FAIL` means the gate failed, is blocked, or has not been directly proven.

## Release decision and unblock conditions

Do not create a tag, GitHub release, installer, or portable release claim for
`0.0.20`. The next public version may be `1.0.1` only after all `FAIL` rows are
replaced with direct evidence. At minimum this requires:

1. A complete checksum-approved, redistributable production model set with
   release-eligible benchmarks and offline CPU execution.
2. Maintainer attestation for the five linked Microsoft static-runtime entries,
   promotion of the reviewed source inventory/notices into the public audit,
   and full application parity for the replacement runtime.
3. A production end-to-end run covering every Session 18 scenario.
4. An authorized private supplied-example run with the false-marker criteria.
5. Installer and portable artifacts built from one clean commit and verified
   for identical binaries, contracts, manifests, checksums, and notices.
6. Clean Windows VM install, portable, offline, path-isolation, repair,
   upgrade, uninstall, spaces, Unicode, and read-only-folder evidence.
