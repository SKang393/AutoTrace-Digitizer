# Marker-center mask-consensus V9

V9 is a new marker-center runner-reproducibility defect class. V8 P3 consumed
its one-time authorization before training because the exact predecessor
center-channel parity maximum changed by `5.662441253662109e-7`. The radius
and artifact maxima matched exactly, and zero optimizer steps ran.

V9 changes only that preflight contract. The exact frozen V8 validation
archive is used only to reproduce the predecessor diagnostic, and every
per-channel maximum must remain within `1e-6` of the preregistered aggregate.
This does not change or waive the separate `1e-5` CPU ONNX parity gate applied
to any newly exported V9 model. V8 case detail and pixels were not inspected.

Before any V9 model execution, 512 training, 128 visible validation, and 160
truth-hidden public procedural scenes were frozen. Their renderer,
degradation, scene-ID, and seed families are fresh and disjoint from V8 and
from one another. The split has zero source overlap, zero truth/prohibited
acceptance overlap, zero truth/mask conflict, and every prohibited point is
present in artifact truth. Freeze evidence records zero model executions and
zero optimizer steps.

only on the fresh V9 train and validation archives. It preserves the fixed
thresholds, artifact gates, zero-error marker gates, two-pass mask composition,
fixed 2.5-pixel NMS radius, CPU provider, and strict model parity gate. P2 and
P3 remain unregistered.
