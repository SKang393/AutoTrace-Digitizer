# OCR production composition V1

This checkpoint composes the exact passing V8 graph-text detector, the exact
official English PP-OCRv5 mobile recognizer, and the exact passing V5 graph
numeric specialist. It does not retrain or rerun any consumed candidate gate.

The general recognizer owns words and unconstrained text. The numeric specialist
can replace it only for a numeric-grammar result at x-tick or y-tick geometry.
That routing rule prevents numeric normalization from creating scientific values
from participant, phase, legend, or annotation text.

`prepare_split.py` freezes one validation and one truth-hidden public archive
before any model execution. Both splits are fresh procedural graph scenes and
exclude Chandler, Generalization, private/article images, external data, and all
predecessor fixture bytes. `sealed_gate.py` is a single-use CPU-only evaluator
that directly executes all three checksum-bound ONNX payloads on the frozen PNG
bytes and records input/output tensor stream hashes. The public gate refuses to
open until the exact passing validation report has been committed and its hash
is included in the public gate identity.

Even a passing composition report remains unapproved and release-ineligible.
Production promotion still requires the same fixture bytes to execute through
the C# production composition, independent marker-stage evidence showing zero
marker creation from OCR text, approved multi-payload model-store discovery,
packaging and notices, and clean-machine offline evidence.

The single authorized validation execution is consumed and failed closed. The
exact three-model composition ran on CPU for all 64 frozen scenes. V8 retained
207 of 320 truth regions with zero false regions, duplicates, or prohibited
structure hits, but missed 113 regions and made only 3 scenes detection-exact.
Misses were 56 of 64 legend labels, 25 of 64 x ticks, 21 of 64 y ticks, and 11
of 64 annotations. All 207 detected regions were recognized exactly: word and
numeric exact match were both 1.0 and character error rate was 0.0. The report
SHA-256 is
`a3d851c043993bdc5546c68dfa26be837c88495600f7cbd214c55ee107ef330f`.
The truth-hidden public archive remains unopened. This composition must not be
rerun, repaired, tuned, manifested, stored, packaged, or approved.
