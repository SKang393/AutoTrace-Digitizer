# Component-context graph text detector V7

V7 is a new OCR detection defect class after the once-only V6 public gate
retained every truth region but accepted seven prohibited structure regions.
Only the aggregate failure counts were used. No V6 public fixture, sample,
prediction record, or pixel was reopened or inspected.

The frozen V7 input combines a tight component-line proposal crop with a
larger scene-context crop and twelve deterministic geometry and structure
features. Its fresh procedural families contain graph axes, ticks, dividers,
markers, connectors, brackets, arrows, legends, and intersections. Chandler,
`Generalization`, private and article images, external datasets, pretrained
weights, downloaded training data, and predecessor public fixture bytes are
excluded.

P1 is the only currently preregistered candidate. It may train once from the
committed checksum-bound runner and configuration. P2 and P3 remain
unregistered. The public archive is truth-hidden from training and may be
opened once only if P1 passes every validation scene and CPU ONNX parity.
Nothing in this revision is production-approved, release-eligible, manifest,
stored, packaged, or authorized for a 1.0.1 promotion.
