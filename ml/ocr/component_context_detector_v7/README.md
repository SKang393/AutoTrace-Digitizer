# Component-context graph text detector V7

V7 is a new OCR detection defect class after the once-only V6 public gate
retained every truth region but accepted seven prohibited structure regions.
Only the aggregate failure counts were used. No V6 public fixture, sample,
prediction record, or pixel was reopened or inspected.

The frozen V7 input combines a tight component-line proposal crop with a
larger scene-context crop and twelve deterministic geometry and structure
features. Its fresh procedural families contain graph axes, ticks, dividers,
markers, connectors, brackets, arrows, legends, and intersections. Chandler,
`Generalization`, private and article images, external datasets, pretrained
weights, downloaded training data, and predecessor public fixture bytes are
excluded.

P1 trained once and passed CPU ONNX parity, but two compact triangle structures
left only 62 of 64 validation scenes exact. P2 changed only the loss from
inverse-frequency weighting to unweighted cross entropy and improved the fixed
validation set to 63 of 64 exact scenes while retaining all 256 truths. One
compact triangle still passed every evaluated threshold from 0.85 through 0.95,
so the sealed public archive remains unopened.

P3 was the final preregistered candidate. Its direct trigger was the P2 report:
the final training loss reached 2.69520371547386e-7 while the remaining
validation false structure persisted. P3 restarted from the exact P1 checkpoint
and changed only P2's unweighted cross entropy to 0.05 label-smoothed cross
entropy. It passed CPU ONNX parity and eliminated false regions, but missed
three of 256 truths at the lowest evaluated threshold. Only 61 of 64 validation
scenes were exact.

P1 through P3 are consumed, V7 is exhausted, and no candidate may be rerun.
Because no candidate passed the fixed validation gate, the public evaluator is
not authorized and its truth-hidden archive remains unopened by training or the
public gate. V7 produces no manifest, model-store payload, or packaging input.
Nothing in this revision is production-approved, release-eligible, manifest,
stored, packaged, or authorized for the `1.0.0` stable promotion.
