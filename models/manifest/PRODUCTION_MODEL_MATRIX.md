upstream evidence dependencies are unavailable. The exact reviewed source-built

Windows load evidence and pass their two release-audit rows. The full production
workflow remains blocked by the missing approved OCR detector, OCR recognizer,
marker-center, and artifact-mask set, so these deterministic runtime approvals
do not make the application or release artifact pair ready.
